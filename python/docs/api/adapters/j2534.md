# J2534

Open a Windows SAE J2534 PassThru adapter for raw CAN with `J2534Adapter`, or
use `J2534NativeIsoTP` for firmware-managed ISO-TP and reusable device handles.
The vendor DLL must match the Python process's architecture.

## Configuration

The configuration is shared by the async and sync APIs. `J2534Config()` discovers
the vendor DLL from the Windows registry and uses 500 kbit/s Classic CAN.
