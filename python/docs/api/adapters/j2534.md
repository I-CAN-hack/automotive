# Native J2534 ISO-TP

These classes expose firmware-managed ISO-TP and reusable device handles on
Windows. Configure the vendor DLL and bitrate with
{class}`automotive.adapters.J2534Config`.

## Synchronous API

`automotive.sync.adapters.j2534` exposes the same native transport and reusable
device handles with blocking calls. Its transport inherits send, receive, and
lifecycle methods from {class}`automotive.sync.transports.Transport`.
